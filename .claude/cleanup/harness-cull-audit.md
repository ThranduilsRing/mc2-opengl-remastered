# Harness cull audit (read-only, HEAD 30e674917, 2026-10-11 night)

Owner ruling: "the harness has a TON of unused and bloated stuff that we need to kill" + "prefer maintained open-source tooling over home-grown". Scope = everything that is not the game: `scripts/`, `tools/`, `tests/`, `.claude/{hooks,cleanup}`, `.mcp.json`, `cmake/`, root scripts, `docs/`. Builds on `dead-infra-inventory.md` (2026-10-09 rulings; DI-1..DI-8 mostly executed) and the G8 retirement (a82cad316: `check-env-registry.sh`, `check-new-gates.py` already gone).

Method (all verifiable from the repo): line counts via `git ls-files` (binary extensions excluded; `tests/terrain/beautify/*.r32` are raw floats, not text, and are excluded from every total below); callers via one `git grep -F` pass over every harness basename, then classified LIVE (a `check-contracts.sh` row, `run_smoke.py`/`smoke_lib`, a registered hook, `.mcp.json`, CMake) vs MENTION (docs, allowlists, coverage registries, comments). "Last touched" is the last commit EXCLUDING the 18 mass sweeps of 2026-10-09/10 (console_child, background-launch, doc-status headers): raw `git log -1` says 2026-10-09 for ~250 files that nobody has worked on since June/July. Verdicts: DELETE (git keeps it; docs go to `E:/mc2-archive-2026-10/docs` as a tarball first), KEEP, MERGE-INTO, REPLACE-WITH (maintained tool). Owner rulings taken as given: modder tools (mc2fx, mc2fx_preview, mc2weapon_gui, meshoptimizer), brain harness, comment/cite guards, typed gate registry tools, ratchets, lane_merge/handoff_append, sim_determinism/saveload_roundtrip/objhash, tidy/, split/, montage_compact, capture_ab, kill_build_tree, console_child, nofocus/exe_guard/lease, build_all_targets, build_contract_harnesses — all KEEP, not re-argued.
