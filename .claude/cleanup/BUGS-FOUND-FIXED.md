## Proof-infrastructure defects that invalidated earlier evidence (for the record)
- The host engine lease was skipped whenever the cursor-guard test switch was set, so three lanes ran three engines at once and flaked tier1 (821690c2b).
- Vulkan captures requested without the umbrella flag silently drew with GL; 22 earlier "VK" capture sets were void (c5b7e0843, c0158be25, index in `.claude/l2cap/index.md`).
- Every smoke, capture and Tracy trace before 2026-10-12 ran at 4K from options.cfg, not the documented 640x480; captures and Tracy are pinned to 1080p since e8437015b, tier1 since c5214e23e.
- A bare `bash` from a Python child started the WSL launcher, so lane_merge's verify step reported failures that never ran (df3db6c67).
- `tools/saveload_roundtrip.py` handed back the PREVIOUS run's testgame.ims as a mission's save when the quicksave fixture never fired (it waits out a movie camera: mc2_03 and mc2_10 at render frame 1000), so two baselines of 2026-10-14 held mc2_01 saves (560eee773 deletes the stale file first).
- The SIMID digest has carried process-lifetime RNG draw counts since 5e0341d37 (2026-10-12); `saveload_roundtrip run` compares the digest text after a load and so can never report a match (see row 27).
