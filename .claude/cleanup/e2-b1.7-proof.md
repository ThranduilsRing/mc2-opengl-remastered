## Conversion decisions

- The six EditorData text members own `std::string`; getters return
  `const std::string&` and setters take a string by value and move it.
  Empty means no text at the former null/empty consumers. No wrapper,
  static owner, string-view member or EString::view is introduced.
- Mission-settings values use the existing optional `objective_text::read`.
  Missing values leave the current member unchanged, matching the previous
  success-only assignment. The shared reader preserves LF-to-CRLF handling.
  MFC GetBuffer inputs enter owned strings through `mc2::str::from_c`.
- MissionName, Author, AVIFilename and DownloadURL retain raw writeIdString
  calls with non-null c_str() values. Blurb and Blurb2 retain the existing
  CRLF-to-LF writer behavior through `objective_text::write`. No writer
  preservation rule, FIT key/order, coordinate, authored model or asset
  relationship suffix is changed in this string batch.
- Local campaign/player/commander block names and selection labels use
  literal std::format calls. Nullable %s arguments use fmt::safe; the former
  %ld arguments use fmt::as_i32. No EString compare, sort or index operation
  occurs in B1.7, so no iequals or ordering helper is added.
- BeautySidecarPreview returns a pointer into the live EditorData mission
  name rather than a value-returning accessor's temporary. EditorData is
  non-copyable and non-movable; synchronous sidecar reads consume the
  pointer before any mission clear/reload/name mutation.
- LinkBrush.h's declaration used LinkAction::LinkInfo even though LinkInfo
  belongs to LinkBrush. Qualifying the actual enclosing type matches its
  existing out-of-line definition and is necessary for clang to parse the
  edited mission-settings caller. No type, layout or behavior changes.
