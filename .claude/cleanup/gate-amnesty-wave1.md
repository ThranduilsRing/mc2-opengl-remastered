# Gate amnesty wave 1 (render side) -- audit ledger, lane 2 / T2

Phase 1 audit at `30e674917` (worktree A:/Games/mc2-lane2, branch claude/lane2-s3). WHAT: one row per Feature / Trace / Retired registry row read in lane 2's files (GameOS/, RenderCore/, RenderWorld/, GameAdapters/, GuiRuntime/, shaders/, the mclib render files). WHY: the owner's amnesty target is < 30 runtime gates; this wave takes the registry from Feature 195 / Trace 156 toward at most 130 / 100 by deleting every gate whose other arm has no live user, folding the VK umbrella members, and naming what stays and why. No code was edited in phase 1; phase 2 (after the orchestrator's veto pass) deletes one family per commit and appends the deletion ledger (section 6).

Facts come from a scan of every typed reader (`gate::get/isSet/str/is/armed/regionTier1Armed/effective<"MC2_X">`) in the C++ dirs and every MC2_X mention in scripts/, tests/, tools/, docs/, data/, cmake/ and the root .bat/.ps1 files (collector in the lane scratchpad; the facts JSON is regenerable). Out of scope: the 82 registry rows whose readers are all in code/, gui/, editor/ (lane 1 territory; listed in section 5).

## 1. Rules applied

- DELETE: the gate's other arm (on-arm of a default-off, off-arm of a default-on, the override of a knob) has no live user in the game, the editor, a smoke parser, a capture tool, a harness matrix, the launcher table or a script that sets it. The row, the reader, the dead arm and the doc line go; the live arm stays as plain code (a numeric knob becomes a named constant). A doc mention, a memory note, a `tools/phase/proofs` transcript or a `capture_baseline.py` TRACKED_FLAGS record is not a user.
- FOLD: a Tri member of `MC2_VK_SHARED_GBUFFER` (`inherits(...)`) folds into the umbrella (ruling 2026-10-09); `armed<member>()` becomes `umbrellaOn()`, the per-member `=0/=1` override is the expendable debug knob (ruling 3).
- KEEP-RULING: `MC2_TERRAIN_AMBIENT_FLOOR_NIGHT`, cliff tessellation, `MC2_GPU_PARTICLES` (+ its parity substrate), readers in a step-4 section-2 file, the two Retired rows (MLR ruling).
- KEEP-LIVE: both arms have a user (named per row). A launcher Engine Options row is a REAL user setting: it stays this wave and is marked SETTINGS (the modern home is a settings entry, not a gate; that conversion is a later wave).
- The renderer default is GL; a GL-only arm is not dead while VK parity is open, so no row here is deleted for 'GL only'.
- `W2` rows are deletions by the rules whose consumer edits are heavy (delivery ledger, positional enum 3, test fixtures x11); they are counted separately and left for wave 2 unless the orchestrator wants them now.
- Flags `VETO-*` mark rows that follow the rules but where the orchestrator may prefer the alternative named in the row (promote a default-off fix, keep an arc seam, keep cooked content reachable). Every flagged row is still a DELETE in the counts below.
