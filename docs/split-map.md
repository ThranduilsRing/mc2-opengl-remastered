Generated by `tools/split/split_map.py --write` from `tools/split/allow/*.json` and the pieces' own header comments; `--check` (the `split_map` contract row) fails when it is stale. Each oversized source file was cut into the pieces below by moving whole top-level units verbatim; the shared declarations of every split live in the `*_internal.h` header listed with it.
