## Desktop-composite capture exceptions (NOFOCUS-FINISH-1)

These harnesses screenshot the DESKTOP COMPOSITE (`pyautogui` / `mss` /
`PIL.ImageGrab`) instead of reading the engine's `glReadPixels` FBO, so an
offscreen window would hand them the user's WALLPAPER. They declare
`offscreen=False`, which `nofocus.apply_env` grants only in a user-present
session (`MC2_HARNESS_ALLOW_FOREGROUND=1`). Even then the window is
SW_SHOWNOACTIVATE, the engine runs with `MC2_NO_CURSOR_GRAB=1`, and the only
z-order change is `nofocus.raise_noactivate` (HWND_TOPMOST + SWP_NOACTIVATE):
no focus, and the mouse stays untouched. Porting one to the engine
readback path retires its entry. Enforced by RULES 6-7.
