## Round 2: lighting correctness (owner: all mechs dark/flat)
Root cause found: the VK mech diffuse sun uses the UNSWAPPED light_dir unless options.cfg SunAxisFix is on (default off, a GL-era ruling). Terrain, props, shadows and the mech's own specular all use the swapped (mc2ToRender) direction, so mech N.L is computed against a different sun than the shadows show. Mechs are lit from the wrong side, so which face looks dark depends on the camera. The ambient hemisphere weight also used render-space .z (a sideways axis) instead of .y (up). Mechs also get flat ambient with no SH sky and no rim.
Dev knob MC2_MECH_FILL (read once, default 0 = unchanged look): 1 = swapped sun for diffuse + sun-sized hemispheric fill (shade side ~40% of sun side) + correct up axis; 2 = 1 + wrapped N.L + mild fresnel rim. Montages: E:/mc2-archive-2026-10/proofs/mech-dark/choices/mc2_{01,10,24}_montage_abc.png (columns: current, 1, 2, current+SunAxisFix diag; rows: two poses).
No default changed. Owner picks, then the choice becomes the default constant.

## Round 3: shipped default (owner picked c)

MC2_MECH_FILL default is now 2 (registered Int gate, clamp 0..2; 0 = original look for A/B). Ships ON: no default-OFF gate added.
Modes >= 1 force the mech diffuse sun to the shared swapped axis (the one terrain, props, shadows and the mech specular use) regardless of the SunAxisFix option; SunAxisFix keeps its meaning for every other consumer, and only mode 0 still follows it.
