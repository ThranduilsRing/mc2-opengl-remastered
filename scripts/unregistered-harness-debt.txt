# TREE-CONSOLIDATE-1 (2026-07-31). Buildable contract-harness directories under
# tools/ that are deliberately NOT in REGISTERED_HARNESSES
# (tools/run_contract_tests.py), one per line, each with a stated reason after
# a '#'.
#
# Enforced by scripts/check-contract-coverage.py arm (e). TWO-WAY RATCHET, the
# same shape as the other frozen-debt ratchet files:
#
#   * a buildable harness dir absent from BOTH the registry and this file
#       -> FAIL. That is a dark check: never built, never run, and
#          indistinguishable from a passing one. This is exactly how
#          tools/class_light_band_harness -- 70 tests, the "17 of 24 missions
#          light the wall facing away from the sun" measurement and the SH-IBL
#          probe sign-flip guard -- shipped unrun on the same day both of its
#          siblings were registered.
#   * an entry here that IS now registered  -> FAIL. Delete the row. Debt can
#          only shrink, and a silent re-add is impossible.
#   * an entry here whose directory is gone -> FAIL (stale row).
#
# A reason is MANDATORY. An unexplained exemption is how a check goes dark, and
# is the failure mode arm (b) already guards for check scripts.
#
# Before adding a row, ask whether the harness could simply be registered.
# Registration is the default; this file is the exception.
