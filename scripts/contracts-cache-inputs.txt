# A row listed here is skipped ("PASS (cached)") when a previous run PASSED against byte-identical inputs. A row NOT
# listed is never cached. Inputs = the specs below + the check's own code, which the helper finds by itself (repo files
# named in the row command, their local imports, repo paths they mention, same-stem sibling baselines).
#
# Spec forms (git-tracked + modified + untracked-not-ignored files are the universe):
#   dir or file path     prefix match          .   everything
#   glob:PATTERN         fnmatch on the path ('**' behaves like '*')
#   !SPEC                exclusion             +ignored   also include git-ignored files (for rows that os.walk/rglob)
# Rule for adding a row: list EVERYTHING the check reads that is not its own code. When unsure, use "." (wider key,
# never wrong). Rows that read an install, a build tree, a compiler or a capture on disk must stay undeclared.
