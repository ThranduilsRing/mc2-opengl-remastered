# scripts/counter-honesty-allowlist.txt
#
# COUNTER-HONESTY-1 -- INVENTORY of sampled diagnostic instruments that ship
# WITHOUT a self-declaring output, i.e. instruments whose log lines are capped
# at first-N but say nothing about it.  Counting their lines in a log does NOT
# count events.  This file is the audit record, not a permission slip.
#
# Read this before drawing ANY conclusion from a capped trace listed here.
#
# HOW THIS FILE IS USED
#   scripts/check-counter-honesty.py rule R2 fails on any first-N print limiter
#   whose guarded block emits no self-declaring token (sample= / sampled /
#   SAMPLE-CAP / "not a census").  Entries here are grandfathered so the suite
#   stays green on the pre-existing population; ANY NEW limiter must either
#   declare itself or be added here deliberately.  It is a ratchet.
#
# WHY THE STATIC-PROP FAMILY IS ABSENT
#   gos_static_prop_batcher.cpp / gos_static_prop_registry.cpp / mclib/bdactor*.cpp
#   were FIXED in this lane rather than allowlisted -- that subsystem is where a
#   sampled [TREE_DIAG] stream and a dynamic-path-only submit_trees counter twice
#   produced published-but-false "no trees" conclusions.  Every limiter in those
#   three files now prints sample=firstN.  Prefer that treatment over an entry here.
#
# KEY FORMAT
#   <repo-relative-path>::<limiter expression as it appears in source>
#   Line numbers are deliberately NOT part of the key so ordinary edits above a
#   site do not churn this file.
#
# TO REGENERATE THE CANDIDATE SET
#   py -3 scripts/check-counter-honesty.py --emit-allowlist
#   py -3 scripts/check-counter-honesty.py --list-limiters   # incl. DECL sites
#
# RESIDUAL RISK, STATED PLAINLY
#   The R2 detector keys on the `s_`/`g_` static-counter idiom.  Limiters using
#   function-local names (`warnCount < 16`, `budget.printed < kMax`, `miss++ < 12`,
#   `w++ < 8`, `seenCount < 12`) are NOT detected and are NOT in this file.
#   Known undetected sites at the time of writing: gameos_graphics.cpp (invalid-
#   texture-handle warn, overlay resolve_fail dedup), gos_terrain_water_stream.cpp
#   (MismatchPrintBudget), assimp_importer.cpp / mech_skel_import.cpp node+clip
#   diags, gameosmain.cpp kMaxLoadPhaseSamples (that one silently truncates the
#   reported TOTAL, not just the list).  This inventory is a floor, not a ceiling.
#
