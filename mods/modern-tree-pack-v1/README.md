# Modern Tree Pack v1

Asset mod: replaces three broadleaf tree families and one crane with modern GLB assets cooked through the static asset pipeline (LOD manifests, cooked textures, byte-identical install/uninstall).
Full details and pipeline provenance: `docs/README.md` and `cook_report.json`. Activate via the launcher mod picker or `MC2_ACTIVE_MOD=modern-tree-pack-v1`.
