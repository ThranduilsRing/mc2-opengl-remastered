# My Explosions (FX-DEFS worked example)

Worked example for the effects sidecar system (`docs/modding-effects.md`): retunes the stock `Fireball` explosion via a single `data/effects/defs/Fireball.fxdef.json` overlay — no C++, no `mc2.fx` rebuild, no whole-blob copy.
Requires `MC2_FX_DEFS=1` and `MC2_ACTIVE_MOD=my-explosions` (or select it in the launcher).
